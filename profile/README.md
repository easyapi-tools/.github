# EasyAPI

Apify Actors for search, social, ads, and lead data — plus a crawlable landing hub.

- **Landing hub:** [easyapi.tools](https://easyapi.tools) · [All tools](https://easyapi.tools/tools/)
- **Run on Apify:** [apify.com/easyapi](https://apify.com/easyapi)

### Start here

| Intent | Landing | Actor |
|--------|---------|-------|
| Demand / Trends | [Google Trends scraper](https://easyapi.tools/google-trends-scraper/) | [Store](https://apify.com/easyapi/google-trends-keywords-discovery-tool) |
| News headlines | [Google News scraper](https://easyapi.tools/google-news-scraper/) | [Store](https://apify.com/easyapi/google-news-scraper) |
| Ads creative research | [Facebook Ads Library](https://easyapi.tools/facebook-ads-library/) | [Store](https://apify.com/easyapi/facebook-ads-library-scraper) |
